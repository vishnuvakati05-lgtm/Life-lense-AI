# LifeLens AI — Privacy & Security Policy

## Principles
1. **Local-First Retention**: User allergen profiles and search history are retained on the client device using browser storage / SQLite and can be permanently deleted with 1 click.
2. **No Audio Persistence**: Voice interaction uses the client-side Web Speech API by default. Raw microphone audio is never archived or used for ad targeting.
3. **Safe File Handling**: Uploaded packaging photographs are processed using temporary unique UUIDs in memory or ephemeral directories with automatic expiration and cleanup.
4. **Restricted CORS**: Backend APIs strictly enforce authorized cross-origin requests.
5. **No Medical Claims**: LifeLens AI acts strictly as an informational assistant and label interpreter, not as a medical diagnostic device.
